# MY ROSTER Web 0.13
PRODUCED BY SLIM · Less Input. More Convenience.

기존 v0.12 기반 업데이트. 스케줄 및 비행지원 JSON 백업을 각각 먼저 생성하고 ZIP 전체를 기존 GitHub Pages 저장소에 덮어쓰세요. 기존 저장 키 유지. OCR 파일 2개는 빈 폐기 파일로 덮어씁니다. 서비스워커 캐시 버전 013.

- 초기 설정: D16/D40/OD/X/E/AL 또는 개별 설정(건너뛰기 가능). 기존 OFF/V 기록은 충돌 없는 경우 X/AL로 변환.
- TANGO XLSX: 본인 미리보기 등록 후 접힌 동료 이름 선택. 선택 인원만 저장. 원본 저장 없음.
- 회사 근무코드 기준표는 설정에서 별도 XLSX 가져오기(보이는 시트의 일반 시간 코드만). 내부 자료 원본/전체 코드표 미포함. 휴게시간 기존 미차감 방식 유지.
- 동료 이전 월 선택 삭제, DST 시간 숨김, NCC 및 LO 편명 토글.
- 비행지원 FUEL SETTINGS: KG/LB, 기종별 탱크 이름·기준량·메모 저장. 기존 B737-800 참고 계산 유지. 사용자 정의 기종은 정적 참고값만 제공하며 자동 우선순위/균등 배분 및 탑승 화면 단위 설정은 미구현. 실제 급유는 승인 절차를 사용.
- FUEL 설정은 비행지원 백업에 포함. 기존 탑승 기록 유지.

검증: JS 문법 검사 및 Node 코드 마이그레이션, 기본 프리셋, 200명 가상 행 파싱 테스트. 실제 브라우저 URL 접근 제한으로 UI 통합 테스트 미완료. iOS 및 Android 실제 기기, 오프라인 캐시, XLSX UI, 백업 복원 미검증. 배포 전 백업 필수.
